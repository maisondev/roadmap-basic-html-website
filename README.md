# Website HTML Básico

Um site multi-página com estrutura semântica HTML, focado em demonstrar boas práticas de HTML puro e SEO.

## 🌐 Projeto

Este projeto é parte do desafio [Basic HTML Website](https://roadmap.sh/packs/html/basic-html-website) do Roadmap.sh.

## 📱 Site Publicado

Visualize o site em: https://maisondev.github.io/roadmap-basic-html-website/

## ✨ Características

- **HTML Semântico**: Uso de tags semânticas como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`
- **Multi-página**: Estrutura com 4 páginas principais (Home, Projetos, Artigos, Contato)
- **Navegação Consistente**: Barra de navegação presente em todas as páginas
- **Otimizações de SEO**: Meta tags de descrição, Open Graph e canonical URLs
- **Formulário de Contato**: Página com formulário semanticamente correto
- **Sem Estilização**: Foco apenas na estrutura HTML (CSS será adicionado em projetos posteriores)
- **Favicon SVG**: Ícone personalizado com as iniciais "MG"
- **Acessibilidade**: Uso de `aria-current="page"` para indicar página ativa, `aria-required` em campos obrigatórios

## 📄 Páginas

1. **index.html** - Homepage com resumo de projetos, experiência e educação
2. **projects.html** - Listagem detalhada de projetos profissionais
3. **articles.html** - Artigos sobre desenvolvimento web (conteúdo ilustrativo)
4. **contact.html** - Página com formulário de contato e informações

## 🎯 Objetivos de Aprendizado

- Aprender a criar websites com múltiplas páginas
- Estruturar sites de forma semântica usando HTML5
- Implementar navegação funcional e bem-estruturada
- Adicionar meta tags de SEO
- Criar formulários com associação correta de labels
- Preparar a estrutura para estilização posterior com CSS
